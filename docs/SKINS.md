# Making a skin for File by File

A skin is a folder with two files:

```
<app data>/skins/my-skin/
  manifest.json
  sheet.png
```

The app-data folder is shown in Settings. Restart File by File (close and reopen it) to
pick up a new skin. If a skin has a problem, File by File says which folder and why, and
skips it. Skins only change how decisions look; the keys and what they do never change.

The built-in skins are good examples: `src/skins/builtin/volcano/manifest.json` and
`src/skins/builtin/space/manifest.json` (generated by `scripts/skins/*.mjs`).

## manifest.json

```json
{
  "format": 1,
  "id": "my-skin",
  "name": "My Skin",
  "sheet": "sheet.png",
  "size": [160, 90],
  "bands": [[0, "#102040"], [66, "#e8c87a"]],
  "scene": [{ "sprite": "tree", "x": 4, "y": 44 }, { "sprite": "wave", "x": 12, "y": 77, "fps": 2 }],
  "file": [72, 50],
  "sprites": {
    "tree": { "x": 0, "y": 0, "w": 16, "h": 24 },
    "wave": { "x": 17, "y": 0, "w": 8, "h": 3, "frames": 2 }
  },
  "animations": {
    "keep":   { "duration": 1500, "tracks": [] },
    "move":   { "duration": 1500, "tracks": [] },
    "rename": { "duration": 1500, "tracks": [] },
    "trash":  { "duration": 1500, "tracks": [] }
  }
}
```

| Field | Meaning |
| --- | --- |
| `format` | Always `1`. |
| `id` | Lowercase letters, digits and `-`. Must not clash with another skin. |
| `size` | Stage size in pixels (32..640 by 32..360). It's scaled up by whole numbers, pixelated. |
| `bands` | Optional background: horizontal color stripes from each `y` down to the next. |
| `scene` | Sprites always drawn under everything; with `fps`, multi-frame ones animate slowly. A scene sprite can also change as decisions add up, see [Scene that changes](#scene-that-changes). |
| `file` | Where the current file's icon (16x16) waits for a decision. |
| `sprites` | Rectangles on the sheet. `frames` copies sit side by side, left to right. `file` is reserved. |
| `sounds` | Optional sound effects per decision, see below. |
| `animations` | One per decision: `keep`, `move`, `rename`, `trash` are required; `delete` is optional and falls back to `trash`. Duration is 100..10000 ms. |
| `variants` | Optional extra animations per decision; each time, one of the main animation and its variants is picked at random. See [Variants](#variants). |
| `music` | Optional id of a built-in song to play while this skin is on (it replaces the chosen built-in station; My Music is left alone). |

## Tracks

Each animation is a list of tracks, drawn in order (later ones on top). A track is either a
sprite or a caption:

```json
{ "sprite": "file", "keys": [{ "t": 0, "x": 72, "y": 50 }, { "t": 0.5, "x": 120, "y": 30, "arc": 30, "ease": "out" }] }
{ "sprite": "boom", "fps": 10, "once": true, "keys": [{ "t": 0.5, "x": 110, "y": 20 }, { "t": 0.9, "x": 110, "y": 20 }] }
{ "text": "TO {dest}", "color": "#ffffff", "align": "center", "keys": [{ "t": 0.4, "x": 80, "y": 6, "alpha": 0 }, { "t": 0.5, "x": 80, "y": 6 }, { "t": 1, "x": 80, "y": 6 }] }
```

- `sprite`: a sheet sprite, or `"file"` for the icon of the file being decided.
- `keys`: where the track is over time. `t` runs from 0 to 1 across the animation, in order.
  The track is only drawn between its first and last key. Optional per key: `alpha` (0..1),
  `scale`, `arc` (a hop of that many pixels on the way to this key), `ease` (`linear`, `in`,
  `out`, `inOut`).
- `fps`: animate a multi-frame sprite; `once: true` plays the frames once and holds the last.
- `text`: a caption in the built-in 3x5 pixel font (uppercase). `{name}`, `{newName}`,
  `{dest}` and `{kind}` are filled in. `clip: [x, y, w, h]` cuts it to a box (for tickers).

## Sounds

`sounds` maps a decision to effects played during its animation. `at` is when, from 0 to
1 of the animation's duration (like a key's `t`). `delete` falls back to `trash`.

```json
"sounds": {
  "keep":  [{ "sfx": "chime", "at": 0.4 }],
  "trash": [{ "sfx": "whoosh", "at": 0.1 }, { "sfx": "explosion", "at": 0.5 }]
}
```

The effects are built into Arch-ade (made in `src/audio/sfx.ts`): `blip`, `pop`, `chime`,
`whoosh`, `sizzle`, `rumble`, `tom`, `tomHi`, `horn`, `splash`, `launch`, `explosion`,
`beam`, `jingle`, `shoot`, `hit`, `hurt`, `jump`, `coin`, `powerup`, `bounce`, `gameover`, `win`. Try them with **Sound test** in the Sound menu. Up to 16 per decision.

An animation (or a variant) can carry its own `sounds` list, which then replaces the
skin's `sounds` for that decision. Skins can also add their own effects to Arch-ade by
dropping a file in `src/audio/effects/` (built-in skins only).

## Variants

```json
"variants": {
  "trash": [{ "duration": 1800, "tracks": [], "sounds": [{ "sfx": "creak", "at": 0.3 }] }]
}
```

Up to 8 per decision. Royal Court uses this so a trashed file is either walked to the
dungeon by the guards or dropped through the king's trap door.

## Scene that changes

A `scene` sprite with `tally` switches to the next sprite in its list each time one of the
listed decisions happens, and stays on the last one. Undo steps it back.

```json
{ "sprite": "pot", "x": 60, "y": 50, "tally": { "on": ["keep"], "sprites": ["pot1", "pot2", "pot3"] } }
```

Up to 16 sprites. Peasoup's soup pot fills up over six stages as files are kept.

## Undo

When you undo a decision in File by File, its animation plays backwards at double speed with
a rewind sound. Skins don't need to do anything for this.

## Art

Use your own art or art you're allowed to use (for example CC0). Keep sheets small: they
must be PNG and at most 4 MB.
